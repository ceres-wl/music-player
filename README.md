# music-player

Dependências:

- [Rust](https://rust-lang.org/tools/install/)
- [NodeJS](https://nodejs.org/en/download)

## Desenvolvimento

Baixar dependências do npm:

```bash
npm install
```

Para rodar o servidor de desenvolvimento:

```bash
npm run tauri dev
# Demora um tempinho na primeira vez
```

> O servidor de desenvolvimento tem HMR pro frontend, mas pra mudanças no backend ele tem que fechar o app, recompilar e abrir de novo.
